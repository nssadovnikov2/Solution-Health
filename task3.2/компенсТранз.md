### Таблица компенсирующих транзакций (Saga Choreography)

| Шаг сценария | Компенсирующее действие | Риск, который устраняется |
| :--- | :--- | :--- |
| **1. Бронирование слота в Сервисе Расписания** | **Отмена бронирования слота** (вызов API Расписания с пометкой `cancelled`) | Пациент забронировал слот, но оплата не прошла или LIS не смог зарезервировать время. Слот должен быть освобождён, чтобы другие пациенты могли его занять. Иначе — потеря выручки и недовольство других пациентов. |
| **2. Инициация оплаты через Платёжный шлюз** | **Отмена платежа / Возврат денег** (вызов API Платёжного шлюза с типом `refund`) | Деньги списались, но запись не подтвердилась (например, LIS вернул ошибку или слот уже занят). Клиент не должен потерять деньги. Иначе — финансовые потери и шквал обращений в поддержку (SD-009). |
| **3. Резервирование времени в LIS (лаборатория)** | **Отмена резервации в LIS** (вызов API LIS с пометкой `cancel_slot`) | Время для сдачи анализов забронировано, но оплата упала или слот в расписании не подтверждён. LIS должен освободить время для других пациентов. Иначе — лабораторное время простаивает, а пациент не приходит. |
