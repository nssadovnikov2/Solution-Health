### Таблица компенсирующих транзакций (Saga Choreography)

| Шаг сценария | Компенсирующее действие | Риск, который устраняется |
| :--- | :--- | :--- |
| **1. Проверка полиса (1С)** | Компенсация **не требуется** (операция read-only). | Нет риска — данные не менялись. |
| **2. Бронирование слота (Расписание)** | **Отмена бронирования слота** (вызов API Расписания с пометкой `cancelled`). | Слот занят, но оплата не прошла или LIS недоступен. Освобождаем время для других пациентов. |
| **3. Инициация оплаты (Платёжный шлюз)** | **Возврат денег (Refund)** через API Платёжного шлюза с idempotency-ключом. | Деньги списались, но LIS не смог зарезервировать время или слот уже занят. Возвращаем средства клиенту. |
| **4. Резервирование LIS (лаборатория)** | **Отмена резервации в LIS** (вызов API LIS с пометкой `cancel_slot`). | Время для анализов забронировано, но оплата упала или слот в расписании не подтверждён. Освобождаем слот в лаборатории для других пациентов. |
